# 任务怪兽 Task Monster

面向觉得任务太大、难以开始的学生。用户自己把任务拆成小步骤，完成一步就降低怪兽血量，全部完成后驯服怪兽。

## 运行

先安装 uv。在终端进入本文件所在目录，然后运行：

```bash
uv sync --locked
uv run streamlit run app.py
```

在浏览器打开终端显示的本地地址（通常是 http://localhost:8501）。终端按 Ctrl+C 停止服务。

## 使用

1. 输入任务名称，添加至少一个小步骤；开始前可以删除步骤。
2. 点击“开始挑战”。现实中完成一步后，点击该步骤旁的“完成”。
3. 查看进度、血量与怪兽状态。误点时可以“撤销”。
4. 勾选清空确认后，可以重新开始。

## 第一阶段限制

- 仅支持当前会话中的单个挑战，没有文件保存。刷新、断开或关闭后可能丢失进度。
- 开始后不能编辑步骤；可确认清空后重建。
- 完成情况由用户自己确认；没有计时、AI、账号或排行榜。
- 怪兽使用系统 emoji，外观会因设备而异。

## 本地验证（可选）

开发时可以在本目录手动运行 tests/test_app.py 的互动测试：

```bash
uv run --locked python -m unittest discover -s tests -v
```

当前没有每次上传后自动运行的工作流。这些本地测试不能代替真实用户试用，也不代表老师的评分。
